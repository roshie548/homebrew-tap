# Homebrew Tap for Proxmux

This is the official Homebrew tap for [proxmux](https://github.com/roshie548/proxmux), a terminal UI for managing Proxmox VE clusters.

## Installation

```bash
brew install roshie548/tap/proxmux
```

Or:

```bash
brew tap roshie548/tap
brew install proxmux
```

## Updating

```bash
brew upgrade proxmux
```
